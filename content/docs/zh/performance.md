# 性能评测

iStack 的原型在多个平台上实现。论文摘要给出了以下结果：

| 指标 | 结果 |
| --- | --- |
| 转发吞吐 | 6.50 Gbps |
| 相对 NDN-testbed 转发器 | 16.25× |
| 缓存包转发时延 | 降低 46.08% |

这些数字说明，把 NDN 放入内核不仅可行，也能在吞吐与时延上取得明显收益。尤其是缓存包的转发时延：内核内的报文缓存让命中路径更短。

> 评测环境、对比方法与完整数据请参考 [论文原文](https://www.usenix.org/system/files/nsdi24-li-tianlong.pdf)。本站只做摘要级整理。
