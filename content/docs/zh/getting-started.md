# 项目概览

NIP 是一个围绕 **iStack** 的研究站点。iStack 发表于 NSDI '24，它把命名数据网络（Named Data Networking, NDN）的协议栈放进了操作系统内核。

## 从主机中心到数据为中心

NDN 用名字而不是地址来驱动转发，数据平面需要为每个报文维护状态。这种设计让缓存、移动性和多路径转发更自然，但也对协议栈提出了新的要求。

已经有不少 NDN 转发器覆盖不同场景，但缺少一个与操作系统集成、可通用部署的网络栈。iStack 试图补上这一层。

## 三个必须同时解决的问题

1. **内核内的名字解析**：报文分流需要名字解析架构。
2. **与地址制架构兼容**：现有内核以 MAC/IP/端口为基础。
3. **性能与资源的平衡**：逐包状态会带来额外开销。

iStack 的答案分别是内核名字解析架构、双层 face 系统，以及与 socket 兼容的接口。
